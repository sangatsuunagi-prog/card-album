アプリ開発の手順フラグ
終わったら [ ] を [x] に変えてください。今いる段階には ← いまここ を付けます。

[x] 1. 要件確認   … 何を作るか・誰が使うか・必要な機能を決める(requirements.md)
[x] 2. 設計       … 画面の構成、使う技術、データの持ち方を決める
[x] 3. 実装       … 実際にコードを書いて機能を作る(index.html)
[x] 4. テスト     … 動作確認をして、不具合を直す
[x] 5. デプロイ   … インターネット上に公開して使える状態にする
                    https://sangatsuunagi-prog.github.io/card-album/ (ホーム画面に追加済み)
[ ] 6. 運用       … 使ってもらいながら改善・修正を続ける  ← いまここ
                    ときどき「データを書き出す」でバックアップ
